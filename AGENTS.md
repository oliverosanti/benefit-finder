# Agent rules

- MCP server tools live one per file in `src/lib/mcp/tools/`, registered in `src/lib/mcp/index.ts`; `supabase/functions/mcp` is generated by the Vite plugin — never hand-edit it. Why: the SDK owns transport and deployment.
- MCP tools are public and read-only, using only the anonymous client and existing public RLS. Why: the owner chose no-login access to the already-public catalog.
- Browser (WebMCP) tools are registered with `useWebMCP` in the component owning the controls and wrapped in `runWebMCPTool`. Why: they must match visible UI state.
